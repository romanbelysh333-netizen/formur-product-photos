# FORMUR | фотографии товаров 2027

Отдельный сайт-каталог для 11 наборов ёлочных украшений. Портфолио `roman-belysh-portfolio` не затрагивается.

## Публикация GitHub Pages
1. Загрузить 33 оригинальных PNG в папку `photos/` (имена должны совпадать с `photos-manifest.json`).
2. Открыть **Settings → Pages**.
3. Выбрать **Deploy from a branch**, ветку `main`, папку `/(root)`, нажать **Save**.

## Файлы
- `index.html` — каталог с поиском, предпросмотром фото и копированием прямых ссылок.
- `photos/` — 33 исходных PNG.
- `photos-manifest.json` — список артикулов и файлов.
- `photo-links.csv` — ссылки для Excel.

Ссылки заработают после загрузки фотографий и включения GitHub Pages.
